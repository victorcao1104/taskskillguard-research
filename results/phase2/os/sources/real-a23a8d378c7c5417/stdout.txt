usage: calibration_manager.py [-h] {check,ensure} ...

Sparse4D calibration manager: check or ensure calibration covers the required
batch size.

positional arguments:
  {check,ensure}
    check         Print sensor count; exit 0 if >= batch_size, 1 otherwise.
    ensure        Ensure calibration exists for batch_size; generate if
                  needed. Prints resolved path to stdout.

options:
  -h, --help      show this help message and exit
