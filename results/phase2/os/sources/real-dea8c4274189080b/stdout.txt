usage: arxiv_search.py [-h] [--max-results MAX_RESULTS] [--category CATEGORY]
                       [--sort-by {relevance,submittedDate,lastUpdatedDate}]
                       [--start-date START_DATE] [--end-date END_DATE]
                       query

Query the arXiv API and emit structured paper metadata as JSON.

positional arguments:
  query                 free-text search topic

options:
  -h, --help            show this help message and exit
  --max-results MAX_RESULTS
                        number of papers to return (default: 20, max: 50)
  --category CATEGORY   optional arXiv category filter, e.g. cs.CL, cs.CV,
                        stat.ML
  --sort-by {relevance,submittedDate,lastUpdatedDate}
                        sort order (default: relevance)
  --start-date START_DATE
                        earliest submission date, YYYY-MM-DD (inclusive)
  --end-date END_DATE   latest submission date, YYYY-MM-DD (inclusive)

Examples:
  python arxiv_search.py "transformer attention" --max-results 10
  python arxiv_search.py "diffusion models" --category cs.CV --sort-by submittedDate
  python arxiv_search.py "graph neural networks" --start-date 2023-01-01
