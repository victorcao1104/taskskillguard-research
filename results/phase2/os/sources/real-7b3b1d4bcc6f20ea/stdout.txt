usage: tracking_commit.py [-h] {init,commit,check} ...

Maintain one structured story state and its deterministic Markdown views. The
language model supplies compact semantic JSON. This tool validates and merges
that input in memory, renders every derived view, then atomically writes
``_tracking-state.json`` last as the single commit point. One book project has
one serial writer; concurrent commits are intentionally unsupported.

positional arguments:
  {init,commit,check}

options:
  -h, --help           show this help message and exit
