usage: myrealtrip_mcp.py [-h] [--endpoint ENDPOINT]
                         [--timeout-seconds TIMEOUT_SECONDS]
                         {tools,call} ...

Streamable HTTP로 마이리얼트립 MCP 도구를 호출합니다.

positional arguments:
  {tools,call}
    tools               사용 가능한 MCP 도구와 입력 스키마를 JSON으로 출력합니다.
    call                MCP 도구 하나를 호출하고 CallToolResult를 JSON으로 출력합니다.

options:
  -h, --help            show this help message and exit
  --endpoint ENDPOINT   마이리얼트립 MCP 엔드포인트(기본값: https://mcp-
                        servers.myrealtrip.com/mcp).
  --timeout-seconds TIMEOUT_SECONDS
                        MCP 연결/호출 전체 제한 시간(기본값: 30.0초).

예시:
  myrealtrip_mcp.py tools
  myrealtrip_mcp.py call getCurrentTime
  myrealtrip_mcp.py call searchTnas --arg query='오사카 유니버설 스튜디오' --arg perPage=5
  myrealtrip_mcp.py call searchDomesticFlights --json '{"origin":"GMP","destination":"CJU","departDate":"2026-05-20"}'
