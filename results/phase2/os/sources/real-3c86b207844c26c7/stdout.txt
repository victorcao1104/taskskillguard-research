usage: compile_paper.py [-h] [--output OUTPUT] [--check-style]
                        [--timeout TIMEOUT] [--auto-fix]
                        tex_file

Compile LaTeX paper to PDF

positional arguments:
  tex_file              Main .tex file

options:
  -h, --help            show this help message and exit
  --output OUTPUT, -o OUTPUT
                        Output PDF path
  --check-style         Run chktex style check
  --timeout TIMEOUT     Timeout per command (seconds)
  --auto-fix            Auto-fix errors and retry (up to 3 rounds)
