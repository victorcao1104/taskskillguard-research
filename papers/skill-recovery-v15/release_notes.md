# v15 paper: safe recovery after a blocked Skill

New manuscript based on the preserved `v15-recovery-mechanisms` experiment. The research question concerns when retained computation, state evidence and trusted execution help safe continuation under fixed permissions.

- IEEE paper: 11 body pages plus one reference page; 189-word abstract; 19 references.
- Three contributions: controlled mechanism comparisons, conditional recovery findings, and causal diagnoses of unnecessary constraints and validation gaps.
- Negative findings retained: Full does not generally beat ordinary repair; structured state does not consistently help; specialist solvers remain strong; automatic execution performs substantive trusted work.
- Runtime oracle assumptions, incomplete total-cost measurement, source-feedback/candidate-budget differences, limited templates, interface failures and exploratory-test overlap are explicit.
- Paper source, PDF, derived evidence, 62-input hash manifest, claim-boundary audit, citation audit and build/check scripts are included.

The release's complete source archive contains the corresponding frozen experiment, saved model responses and all earlier tracked versions. A full clone retains intermediate Git history and tags. Repository access is required because this remains a private project.
