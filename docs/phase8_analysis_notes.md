# Phase 8 analysis implementation notes

The questions and estimands remain those in `phase8_analysis_plan.md`. The analysis implementation was developed with synthetic fixtures. Production source and data were frozen by the parent task before this analysis implementation was complete. The parent supplied aggregate model results while final implementation checks were underway; the implementation source checkpoint therefore is not claimed to be pre-outcome. The analyst did not directly open production observations until the synthetic tests passed and the source checkpoint was saved. The final correction before that checkpoint concerned nested cached/reasoning token locations, not a change in estimands. This is local provenance, not external preregistration.

Run `python scripts/analyze_phase8.py`, or import `analyze_phase8` and call `analyze()` without arguments. The latter writes the immutable bundle and returns its summary. For tests, `analyze(truth_rows, observations, ...)` returns the entire report with optional output writing. The default inference settings are 10,000 paired authored-family bootstrap draws and seed 8008. `null` marks undefined rates and intervals.

The primary grid is reconstructed from truth cases, the two frozen models and D/F/T. Missing responses become explicit invalid observations. Planned repeat jobs are retained when absent as well. Invalid predictions have a separate confusion column and count as incorrect at every candidate axis. Candidate scores store all three axes once per candidate. Exact-case correctness requires all candidates and all three axes correct. Per-axis exact cases are also reported. Family-balanced accuracy averages candidates within a case, cases within a family, then equally weights families. Heldout and regression splits are never pooled in treatment estimates.

For F, global facts are counted once per world and site facts once per world/site. Fact wrong counts cover well-formed responses; invalid responses have their own expected-field counts. Acceptance requires an entirely correct fact response. Label accuracy conditional on acceptance is undefined if no responses pass. Fact error locations are compact world/field or world/site/field records. Repeat agreement compares complete three-axis label sets and complete factorized facts separately; invalid or missing responses cannot establish semantic stability. F versus D bundles fact representation and deterministic label reduction, so it cannot causally isolate either contribution.

Recovery pairs match case, world, quota and fault. Each saved pair holds success and all cost deltas once. The summary reports success wins/losses and family-balanced intervals, all-pair and both-success charged-call/planning deltas, missing metric counts, and positive/negative/zero family means. Future paths can diverge under identical fault schedules. Pairing does not assert identical later observations.

Integration strata use all supplied worlds. No-alternative and no-initially-feasible-alternative are distinct. Initial feasibility starts a fresh enforcing receipt-aware `_Machine`, uses the same `_estimate` as Phase 8 recovery, and respects quota 16. It does not reuse the first post-failure selection log or unguarded reference execution. Gate sensitivity means observed paired success disagreement between all-allow and all-block for the same case/world/quota/fault/policy. Unknown control results cannot establish sensitivity. Pipeline summaries report trusted grant rejections, including original-route rejections attached to model false-allow candidates. A false allow includes separate true-no, true-unknown and true-NA counts; an unknown aggregate label does not itself assert that every supplied world is unauthorized.

Historical comparisons include only the same Phase 7 24 cases in the new regression split: fresh D versus old B1, and F versus old B2. They are descriptive, with acquisition time and (for F/B2) protocol differences acknowledged. Tool execution counts, charged calls, planning steps and simulated effects are separate work measures; zero unauthorized committed effects are attributed to the trusted gateway, not exclusively to model judgment.

The output bundle consists of `summary.json`, `candidate_scores.jsonl`, `case_scores.jsonl`, `fact_scores.jsonl`, `paired_details.jsonl`, `gate_conditions.jsonl`, `initial_feasibility.jsonl` and `failures.jsonl`. Every output is preflighted before any write. Re-running with identical inputs is permitted; different bytes raise an immutable mismatch rather than replacing evidence. Input file hashes identify the evidence actually analyzed. Incomplete execution jobs are retained as failed runner outcomes. Failure references identify either raw API evidence or the source execution condition.

All confidence intervals are exploratory; there is no multiplicity correction and only 12 new authored families. Candidate counts, worlds, repeats and bootstrap draws are not independent sample sizes. The experiment does not establish real-world prevalence, unseen-language generalization, graph benefit, universal policy dominance or a model speedup over full enumeration.
