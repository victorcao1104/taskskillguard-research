# Phase 9 analysis contract

Locally prospective; lock before heldout acquisition. The independent reference is not tuned using production outcomes.

## Primary endpoints

1. New-family completion difference: conditional minus aggregate gate at preflight=true, calls policy, planner 512, cache=true, observation budget2. Also compare preflight on/off within each gate. Four fault strata retained; report pooled paired conditions as dependent conditions, macro-family mean and bootstrap.
2. Query efficiency: proven typed labels / all candidate-axis labels at budgets2/4/8/full, by model and Q0/Q1, paired with heuristic and seeded random. A proven intrinsic unknown counts as resolved; budget unknown does not. Every claimed proven label must equal independent truth. Report query invocations, interpreter steps, first complete resolution position and actual API tokens/cost; a graph advantage requires positive paired evidence over identical source information, not only final accuracy.
3. Factorial typed correctness: for each axis, model x dedup x tool x reducer (0=model supplied labels;1=deterministic reduction of same response). Invalid response=incorrect for every label, also report validity conditional accuracy with denominator. Main effects averaged over the other factors, interactions, joint correct case count and unknown/NA confusion. Direct and reduced labels are dependent outputs of one response, not randomized prompt conditions for the reducer.
4. Recovery: calls versus priority and risk versus calls within equal fault/cache/planner budget, only new structural families. Report completion wins/losses, charged calls on both-success pairs and all conditions, planning_units, audit work, modeled latency, ambiguous-stop incidence/risk scores, cache savings and budget exhaustion. Values of unknown commits and weights are synthetic metrics, not real incident probabilities.

## Additional evidence

- All 72 old cases are execution regressions and descriptive same-case v8/v9 comparison; do not compare disjoint denominators as improvements.
- Query-to-execution pipeline uses only paid original-query facts; missing evidence remains unresolved. Compare model/graph with heuristic/random at8/full with matching runtime controller. Prove supplied evidence mode performs no uncounted audit simulations. Account query work separately from planner.
- Observable and hidden families, zero/one/two observations, inactive/missing evidence are separate failure categories. `unknown` from semantic disagreement, resource limitation and ambiguous commit are different variables.
- Stability repeats: six hash-selected families, one case each; A10/Q0, eachmodel, two additional calls. Label equality and query-order equality are reliability diagnostics; not extra independent samples.
- Bootstrap primary macro-family contrasts with10,000 resamples seed9009, percentile2.5/97.5. Fixed12newfamilies; no confidence over all possible workflows, no multiplicity-adjusted confirmatory claim.
- Store raw per-case/per-candidate/per-condition tables, graph source-equivalence audit, typed distribution, novelty, pipeline failures, monetary ledger and release hashes. Publish null/negative findings and exact policy losses.

## End-to-end interpretation

All policy effects are within the declared finite hypothesis set. Observation and exact local interpreter capabilities are assumed trusted; observations outside the permitted schema are not invented. Operational preflight is fault-blind and cannot guarantee success under later failures. Independent interpreter agreement establishes the implemented finite semantics, not correspondence to real external APIs.
