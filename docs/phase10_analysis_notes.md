# Phase 10 independent analysis contract

The analysis author read the prospective design, production interfaces, and older analysis helpers before seeing new heldout cases or outcomes. Scoring was developed against hand-derived toy rows. Production and data freezes were reported by the coordinator before permission to inspect the new reference material. Analysis never invokes a model, generator, solver, or runtime and never fills missing evidence from truth.

`python scripts/analyze_phase10.py` reads frozen saved outputs, checks freeze hashes and chunk manifests, and writes immutable `results/phase10/analysis/summary.json` plus chunked detail tables. Its pure API is `summarize(truth, observations, queries=(), interface=(), recovery=(), integrated=(), *, models=..., draws=10000, seed=10101, old_pairs=(), accounting=None, input_manifest=None)`. `main(argv=None)` is also callable. `python scripts/plot_phase10.py` renders static PNG/PDF figures and saves the source values used for them.

Primary comparisons retain all invalid and exhausted acquisitions, incomplete query evidence, and runtime failures. Missing registered execution jobs become explicit failed conditions. Missing acquired streams remain in first-decision and all-stream denominators. Per-decision validity uses the adaptive number of attempted decisions and is descriptive; it does not provide an equal-length decision experiment. First validity, whole-stream validity, prefix validity, provider-or-possible-provider requests and local decision attempts have distinct denominators.

Diagnostic coverage checks every claimed proof against the independent typed truth, on authorization/current-route/catalog axes separately. A proved intrinsic unknown is resolved. Any unproved label remains budget unknown even if its displayed value is `unknown`. Authorization completion is the original-world evidence contract and does not imply diagnostic completion. Query families weight cases equally; runtime contrasts first average paired dependent conditions within each family. Bootstrap intervals use 10,000 family resamples with seed10101 and remain exploratory without multiplicity adjustment. New and regression cases are reported separately.

Falsifiable nulls are retained: goal observations need not improve completion; shorter protocols need not improve validity or unconditional evidence; authorization stopping need not reduce work without losing completion; risk selection need not dominate call or priority selection. Goal versus authorization observation is matched at budget2; goal budgets0/1/2 and v9 are explicit controls. Preflight-off remains diagnostic. The historical sixteen preflight losses are a fixed regression subset identified from the unchanged Phase9 pair table, not fresh evidence.

Execution work is a vector, not a scalar CPU estimate: query interpreter invocations and steps, goal observations and their charged planning work, planning units/steps, provider requests, and real gateway calls are separate. Runtime scenario rows repeat per-case acquisition evidence across worlds and faults. Their sum describes those scenarios, never the unique campaign invoice. Prefix model-cost attribution is separate from all acquired spending, which always retains later decisions and unknown reservations. Actual saved interpreter work is reported only on matched conditions with unchanged end-to-end completion, with successful pairs also identified.

Source/graph/padding comparisons include both graph-minus-source and graph-minus-inert-character-padding. Character matching is not tokenizer matching. Full/batch/next differ in feedback frequency and output burden as well as output schema. Recovery Pareto counts require no worse completion, charged calls and declared synthetic mutation risk, with at least one strict improvement. They do not establish universal optimality or real-world risk.

All claims concern finite synthetic programs. No real Skill safety, broad injection defense, external preregistration, global stopping optimality, total CPU, or campaign invoice savings follows from this experiment.
