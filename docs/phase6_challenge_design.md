# Phase 6 supplemental challenge — prospective after first offline result

This amendment follows the preserved first offline evaluation and precedes supplemental model collection. Main 36-case/336-condition campaign remains unchanged. Review found no explicit authorization=no or implementation=no labels in the 24 held-out cases, and 576 search/checkpoint recovery pairs tie on completion and charged calls. These findings are retained, not repaired away. The supplement is a targeted mechanism test, not an unbiased new population estimate or confirmation of search superiority.

## Targeted negative and selection coverage

An independent author creates 12 additional cases / 6 structural families, two paired variants each. Every original contains an optional effect whose grant is allowed in one variant and denied in the other, while the same legitimate goal remains achievable through alternatives. Non-necessity is computed by site intervention, not authored as a label. Include branch/call/repeat/dataflow compositions. Alternative catalogs contain costly and cheap successful legal routes, with catalog order counterbalanced across the six families. Original failure can therefore leave an actual selection problem; the main all-mutating-grants removal was largely infeasible.

These cases are authored after reading the coverage finding but without production implementation or model outcomes. Frozen original parser/truth/protocol remain unchanged. Save separate fixture freeze and first results. They add negative controls, not replacement results. The source prompt's omitted 100-step/key-conflict clauses are acknowledged; no planned reference route or intervention may trigger either omitted rule.

## Equal planning control

Keep all four original strategies. Add two strategies implemented in a new module using the same production VM: `first_feasible` and `search_equal`. Both run the original and its retry, then simulate every remaining alternative with identical public state, grants, receipts, trusted goal, 100-step per-route bound and remaining charged quota. Both filter to routes predicted to complete within remaining quota. First-feasible chooses catalog order; search-equal chooses minimum charged calls, breaking ties by catalog order. If none are feasible both stop safely with no_feasible_route. Both have maximum four actual attempts and record all planning work. Thus primary cost-selection contrast uses identical planning capabilities and effort; its success may tie. Frozen earlier search/checkpoint remain diagnostic comparisons.
