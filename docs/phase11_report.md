# 第十一轮：面向论文的证据契约研究报告

本轮把研究问题收窄为：**在什么明确假设下，哪些证据足以停止查询、批准一条能完成目标的路线，以及在提交结果不明确时合法继续？** 全部实验使用合成数据，不新增真实 Skill 实验、不依赖人工标注。论文初稿见 [manuscript](../paper/phase11/manuscript.md)，逐项主张与证据见 [claims](../paper/phase11/claims.md)。

## 1. 这一轮得到的核心结果

目前有一组可以支撑论文写作的、边界明确且可复现的结果。价值在于把不同类型的不确定性分开，用可执行证据验证停止和恢复的条件，并揭示模型、图表示和宽松重试的局限。它还不能支撑“新的通用安全算法”“真实 Skill 安全性已得到证明”或“模型优于强规则”的主张。也不能保证某个会议接受。

| 问题 | 结果 | 可以支持的解释 |
|---|---|---|
| 有足够证据后能否停止？ | observe-cover在预算12下，家族平均查询7.750降到3.014；完成率均为81.944% | 在本契约内，继续诊断不总是执行所必需 |
| 是否必须确定唯一世界？ | 挑战集9个家族在多个兼容世界下仍能找到共同成功路线 | 决策所需证据可以少于完整环境识别 |
| 模型是否胜过强启发式？ | 同一36个实际世界：启发式30/36，Luna29/36，mini28/36；模型查询更多 | 本轮没有模型优势证据 |
| 图是否带来稳定增益？ | 两模型图与等本地token长度填充的完成数相同 | 图对源码的局部收益不能归因于图语义本身 |
| 恢复能否改善可确认完成？ | 两种终止状态故障各恢复178/178个已触发、可认证执行的可确认完成；部分物理目标原已达成 | 收到可信提交记录或有fencing的终止未提交证明时可以继续 |
| 不明确状态能否直接重试？ | pending/缺失/过期/不匹配状态仍停止；盲目换ID重试反例产生重复效果 | “没有记录”不等于“原操作永远不会提交” |

注意两个完成率分母不同：81.944%是36家族内先对全部世界/变体平均、再等权平均；对应原始成功世界行为178/218。83.333%=30/36是模型比较所用的每家族一个实际世界。不能混用。

## 2. 为何这比继续堆场景更适合写论文

前几轮容易把授权判断、目标完成、诊断完整和提交恢复放在同一个unknown里。本轮定义了四种可以直接核验的状态：

1. **certified**：同一条路线，在所有兼容世界中都有真实购买的成功执行记录。
2. **infeasible**：每条路线都有失败反例，且剩余允许观测无法进一步区分世界；这是共同路线契约的不可行。
3. **unknown**：还没有足够证据，可能因为查询顺序/预算、观测不可用，或者尚未证明不可行。
4. **observation mismatch**：观测不在声明的模型中，拒绝把空集合当作成功证明。

由此可陈述并验证四条有限模型命题：正证书的可靠性及其在真实细化下继续有效；负证书的稳定性；不可区分世界没有共同路线时的机会边界；本显式收据语言中至少需要每个兼容世界一份成功记录。详细证明和独立小状态枚举见 [theory](phase11_theory.md)。这些是条件明确的简单命题，不能冒充全新的主动学习理论。

理论也纠正了一个重要过度主张：停止后保留的是**成功路线的有效性**，不是“未来永远选择同一条路线”。670个匹配正前缀比较中，两边都成功，但完整执行结果相同的只有621个。新证据可能让排序更靠前的另一条路线也被认证。

## 3. 数据与设计有何加强，又有什么缺口

新生产实现与分析规则先冻结，模型运行前再冻结数据。独立任务中的生成器作者没有读取新生产实现或模型结果；它不是人类标注，也不代表现实分布上的独立抽样。

- 主集48个样本、24个结构家族，每家族两个词面变体。
- 聚合检查发现主集可行的完整观测类全部是单世界。因此在模型结果出现前补充了24样本、12家族挑战集，原主集完整保留。挑战集含多世界共同路线、每世界各自可行但没有共同路线、以及观测没有收益的反例。
- 另有12个规模扩展样本，来自同一构造，单列报告，不当成12个独立家族。
- 主集8,672个小状态检查可重算；挑战集371,072个状态穷举，另外6个较大划分只做180项边界检查，不写成全部穷举。
- 独立解释器与生产/实际执行器比较1,006个世界×路线。原始记录有2处错误名字符串差异；只规范化变量名后语义全部一致，原始差异保留。

挑战集的设计受到主集聚合覆盖缺口启发，所以它不是从一开始就完全未触碰的随机测试集。报告将主集和挑战集分别呈现，不用大总数掩盖这一点。

## 4. 查询与unknown：改进发生在哪里

确定性实验共12,320条件，比较original-first、route-cover、observe-cover、固定种子的random，预算2/4/8/12/full，以及停止开关。预算12时observe-cover的平均查询减少4.736，描述性家族bootstrap区间为[-5.556,-3.944]；完成率没有下降。解释器步数29.000降至6.111，证书配对检查69.111降至50.611。选择器自身评分、解析和独立验证器CPU不在这些计数内，因此不能叫“总计算减少”或“实测加速”。

observe-cover在该预算下对全部218个实际世界行都得出终态：178个成功证书、40个负证书、0个unknown。**这不代表把所有任务都做成了。** 对不可观测地区分、且没有共同路线的类，再加模型或查询预算也无法在当前契约内安全认证。扩大允许观测、允许合法条件策略，或者更换路线目录，才可能改变上限。

288条模型流程中，230条正证书、43条负证书、15条unknown。独立真值把这15条分为：10条本来可认证但未获得足够证据，5条还没把稳健不可行证明出来。两次API错误是另一维度的故障，不该与内在不可判定混为一谈。本轮没有预算截断、没有传输结果未知。

## 5. 模型、图和简化协议的真实结论

模型选择与启发式使用同一组查询、同一预算、同一实际世界、同一证书和执行器。主集上两模型和启发式均为21/24；挑战集上分别为Luna8/12、mini7/12、启发式9/12。平均查询分别4.583、5.639和3.000。所有对照和失败都保留，不能改用弱规则作为主基线来制造提升。

图相对源码让Luna多完成1个家族，mini没有变化；图相对填充两模型均没有多完成任务。图—填充查询差为Luna-0.278、mini+0.139，描述性区间都跨零。图是源码的冗余结构，没有新观测；当前小语言中，直接识别观测分区和待覆盖路线的启发式已经很强。这里没有足够证据证明图贡献，更不能把区间跨零解释为证明图永远无效。

协议方面发现了一个确定的历史实现问题：旧解析器把13条包含明确commentary与唯一final_answer的完整响应当作多答案拒绝。新解析器按消息phase严格选择final，仍拒绝多final、未完成、拒绝、工具调用、重复JSON键及非法ID。对旧1,587条响应重审后合法数从1,562变为1,575，无新增拒绝；**没有补造那13条之后从未发生的查询，所以旧实验指标不改。**

本轮前瞻运行1,605次请求中1,603条合法、2条HTTP400。输出上限、证书任务和协议同时改变，不能把所有改善归功于“输出更简单”。

## 6. 提前停止：同时报告实测费用和离线反事实

独立采样的source-online/source-fixed流程中，Luna平均查询从7.639降至4.583，mini从7.750降至5.639。每流程保守费用均值分别减少$0.003521与$0.008588。两模型聚合完成数相同，但Luna存在一个家族变好、一个变差，不能写成逐样本完全等价。

670条正前缀离线对照验证“已有见证继续有效”，不能把离线删掉后续请求算成实际省下的钱。报告中的费用收益来自真实提前停止、没有发送下一次请求的独立在线流程。两种证据分别支持不同结论。

## 7. 合法恢复：最清楚的正结果和最重要的限制

15,696个恢复条件保留没有证书的样本和故障未触发的情况。在一次状态查询可用时，对“已提交但回复丢失”和“已终止且未提交”两类故障，terminal-status各得到178/218世界行的**无错误终止且目标满足**；严格停止均为0/218。按家族等权是81.944个百分点的提升。仅在已触发且有证书子集看是178/178，不能把这个有利子集写成全体100%。

这里还必须区分“物理目标已经达成”和“控制器可以确认无错误完成”。回复丢失条件中，严格停止的84/218行其实已经达到物理目标，家族平均38.889%；terminal-status对应81.944%。所以实际物理目标的提升是43.056个百分点，而可确认完成的提升才是81.944个百分点。终止未提交条件两者一致。最终复核发现这一解释风险后，新增了独立标为事后的 [physical_goal分析](../results/phase11/physical_goal/summary.json)，没有改掉预先指定的主指标或旧结果。恢复的收益既包括确认已经发生的事，也包括完成剩余步骤，不能全算成新增进度。

恢复依据绑定操作ID、负载、epoch和授权上下文。提交记录支持复用已有结果，终止未提交记录还必须保证旧请求被阻止再次提交；pending、找不到记录、过期或签名不符都不足以继续。反例实际复现：原请求仍在处理中，查不到记录就换新ID重试，随后新旧请求都提交，出现重复效果。

同ID去重依赖更强后端，不是同能力对照。它能恢复提交回复丢失，却在当前实现的终止未提交状态停住，因为原ID已终止。因此不能简单把某条恢复策略宣传为所有情况下最好。

零未授权效果首先来自网关强制授权。生产返回的该计数恒为0，不能把它当成独立测出的攻击成功率。另有不导入生产模块的事后轨迹审计：42,846个记录位置中28,482次实际执行、14,364次空执行；63,622个提交事件（50,608个修改类事件）逐项重查授权与逻辑身份，未授权提交和重复修改均为0；语义反例中40次未授权尝试均被拒绝。审计仍依赖模拟器完整记录轨迹，因此是记录一致性验证，不是实际攻击评测。

## 8. 与修复前相比，应怎样准确表述

| 旧问题 | 本轮处理 | 仍不能声称的事 |
|---|---|---|
| 授权完整被误当作执行充分 | 共同路线的完整成功记录，检查精确目标 | 没有增加全信息完成上限：新旧均178/218 |
| unknown混合缺证据与不可行 | 正证书/负证书/未决/观测不匹配分开，独立真值归因 | 不能靠重新命名把不可行算作成功 |
| 提前停止只做事后重放 | 真实在请求前停止，另做同前缀见证检查 | 不能保证独立模型采样逐任务结果相同 |
| 多文本消息被一概拒绝 | 按明确phase选唯一final，保留旧错误证据 | 不能补造历史adaptive continuation |
| 未提交与尚未提交不清 | 增加pending/fencing/身份绑定及迟到提交反例 | 不是对真实分布式后端的验证 |
| 真值与实现可能共享错误 | 独立生成与参考解释、冻结、穷举和隔离复放 | 作者共享任务契约；不是完全无共享假设 |

## 9. 可复现性、费用与写论文的建议

确定性隔离复放29,240条件、端到端隔离复放13,824条件，共173个受限无网络容器，所有结果与本地相同。其中8,664条顶层结果为空；查询策略包装记录内还有执行字段为空的情况，不能把剩余记录全部算成实际执行，更不能虚称43,064次成功执行。独立轨迹审计明确给出实际执行数，并不包括218条新旧契约比较。模型原始请求/响应、两次失败、累计预算、数据、各家族效应、六张图及其CSV均保存。

本轮费用保守上界$3.765178875；累计$22.652988125；授权累计上限$29.551575125，尚余$6.898587。这是按token上界和失败预留计算，不是账单。旧37,907个文件与存档点由发布验证逐一检查。依赖和分词器缓存安装后，可离线重放，无需API密钥；重新向模型取样是另一个付费随机实验，不属于精确重放。

建议论文以“受限工作流中的可检查证据契约及其边界”为主线，模型与图作为有价值的负结果，恢复作为同一证据纪律的第二个实例。已有ECD/决策区域、shielding、proof-carrying code、RIFL等直接前作，必须明确引用。当前结果足以组织严谨的论文初稿，但新颖性强度仍需目标期刊/会议与审稿判断。

如果继续研究，优先顺序应是：①用独立于当前生成器的外部合成语言/生成器做迁移；②实现真正的决策区域算法与静态证明对照，检验显式收据成本是否过于保守；③引入动态状态和证书失效/重新认证，扩大契约适用范围；④只对具有信息论或计算结构差异的任务开展模型重复试验。不要靠继续增加相同结构的种子、放宽成功定义或删去失败来制造论文结果。
