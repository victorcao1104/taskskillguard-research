# 冻结前设计修订与可主张的范围

日期：2026-10-15。`design.md` 是初始计划，不是所有条目已经满足的证明。本文件及最终报告记录实际实施的差别。

## 数据与标签

- 从 skills.sh 的 9,547 个 completed 记录只读抽样；4 个缺少 SKILL.md，候选总体 9,543。选 180 个包、90 个含脚本，按 category × script-presence 分层轮转；这是有意均衡样本，不能用未经加权的候选比例估计总体恶意率。
- 选中样本的发布者、仓库和完全相同内容合并为 123 个家族；分为 99 development、46 validation、35 held_out_test。近似复制与未选中样本之间的传播关系未穷尽识别。只用数据集 A，不重复纳入数据集 B。
- 30 个 pilot 真实包来自 development，获得用户明确授权后才向 OpenAI 发送最多 24,000 字符、12 文件。真实 held-out 包没有发送给模型。
- 132 个合成案例 = 6 模板 × 2 数值 fixture × 11 场景。标签是研究者编写的有限规格，由实际 VM 输出和调用轨迹核验，不是人类双标注，也不是自动证明的通用必要性。
- email、database 两模板留作模型测试；实现期间已经运行过所有模板的机制测试，且 database 与 CSV 共用字符串变换。因此只能称“冻结后首次模型测试响应”，不能声称完全未见任务分布。

## 观察后修正

1. 初始设计在信息流场景中只给守卫补发合法 DONE，造成效用比较混淆。修正为所有配置共享同一动作表（非法流出加合法 DONE），删除隐式补发。旧 144 例结果在 `results/pre_review/`，正式表仅含修正后的 132 例。
2. 重放失败曾容易被误读为任务必要。现在 original / neutralized replay / trusted reference 都实际从空状态运行，重放保留四类状态；仅可比且 core 与 goal 均保留时提供非必要证据。参考执行只证明本 fixture 存在替代路径。
3. 阶段从可信 runtime 的枚举器读取，不接受 skill 指定的 step；拒绝时钟回退。租约次数按 operation/resource 的累计计数计算，不是每规则独立 quota。
4. 真正执行的工具、对象、payload 与独立冻结合同用于运行评分，不依赖模型提供的 action ID。额外调用和重复 ID 不会逃过评分。
5. 正式 development 首次并发运行触发 Z3 共享默认 context 的 C++ assertion。中止进程，改为每次比较独立 context，加入 90 次六线程比较测试；已缓存的 API 响应复用，未结算预留费用保留为上界。这个故障不是模型不安全率。
6. pilot 的三个分类错误暴露出“把实际发送内容想象成修复后的 DONE”及“坏前置步骤污染独立合法读取”的问题。检测提示加入明确说明；正式开发、验证、测试使用同一修正版提示。旧 pilot 不纳入正式指标。
7. 独立复核复现同请求哈希并发双发及缓存覆盖，修为每哈希互斥和原子写入；旧派生结果存 `results/pre_cache_review/`，正式结果从现存 raw 重新解析。历史缺失 raw 的账本项仍计费，不能声称所有历史响应都完整保存。收紧 contract 字段、graph 操作枚举及资源原文定位，均由新增失败测试驱动。

## 可比性与边界

- 合成 V1 的图由生成器写出，衡量显式动作表示的帮助，不测自动图提取精度。真实 V1 用 bounded lexical/AST 图；Q-LLM 提取作为独立审计，不替换自动图后再挑选有利结果。
- V3–V5 工具实验使用研究者提供的精确 task policy，属于 oracle-policy 控制。模型生成合同另行测量；没有把模型错误合同与强制器串成一个端到端自主 agent。
- P/Q 分离只实现“可信任务生成权限”和“无工具 parser 读不可信文本”的组件隔离。不是完整 CaMeL 双模型解释器，图内容不拥有授权能力。
- 可信 VM 仅有内存文件、公开字面量、虚构令牌和 mock sink。没有 Docker daemon，未执行任意真实 shell/Python。真实样本没有动态安全结论。
- textual guard 是模型一次性选择动作子序列时的提示；没有多轮修复、真实浏览器或 AgentDojo 工作流。一次性计划失败与工具调用强制失败分开报告。
- 高授权真实任务只明确授权一个有具体对象的候选动作；缺少资源时仍未决。三元组是研究者生成的假设任务，不能反推出包的恶意意图。
- 来源标签只覆盖显式值流及本 VM 内的组合；没有声称覆盖 Python 任意对象、隐式控制流、异常流、竞态或操作系统旁路。
- 当前 post_task_reuse 的重复读取发生在 runtime step=3，expires=3，实际由 max_uses=1 拒绝；主消融证明租约次数限制，不能单独声称时间到期效果。时间窗在单独确定性探针中检查。
- 仅 exact-resource 策略可由 Z3 比较；UNSAT 只在受支持语义内证明子集。未知结构、工具、路径拒绝/未决，不视为安全。
- 两次重复响应、十二个数值 fixture 不能当十二个独立家族。家族数 3/1/2 极少，CI 仅作描述，不支持强外推。
