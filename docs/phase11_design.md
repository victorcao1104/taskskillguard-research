## Research scope and alternatives

The central question is when executable evidence is sufficient to authorize a finite workflow and cease acquisition, and which trusted evidence permits continuation after an ambiguous commit. This is a concrete instantiation of known decision-region identification and transactional recovery ideas, not a claim to invent active testing or exactly-once execution. A protocol parser repair is an engineering control. A valuable outcome can be a negative result for models and static graphs.

Three alternatives were considered: continuing candidate-label classification; making a larger opaque planner; and a small checked certificate interface. We select the third because it separates acquisition quality, proof sufficiency and runtime behavior. Diagnostic labels remain in old immutable results but are not the new execution contract. This is a new contract comparison, not an isolated patch effect on Phase10.

RQ1: Does a route certificate attain safe task completion using fewer acquired facts than exhaustive auditing? RQ2: At matched information and query budgets, do model policies or redundant static graph representations improve over adaptive public-information heuristics? RQ3: Does stopping before the next API request reduce measured acquisition cost without reducing certified fault-free completion? RQ4: Can bounded trusted terminal-status reconciliation recover ambiguous mutations without duplicates, and what assumptions are necessary?

## Finite contract

The public input is source, alternate route ASTs, a finite closed catalog of initial worlds, grants, an exact goal, allowed immutable initial observations and a shared effect quota of 32. The environment privately selects the actual world. World catalog coverage, immutability until execution, deterministic VM semantics, and truthful atomic query execution are explicit assumptions. A run query audits one world/route using the same guarded, receipt-reusing VM as fault-free actual execution. It does not identify the actual world. An initial-observation query returns a trusted file presence/value or grant bit and filters compatible hypotheses. Each costs one query; interpreter steps and effects are counted separately. No selector can invoke an interpreter except by buying a listed query.

A positive certificate references cached successful guarded runs for one route in every currently compatible world. Its witness route remains valid under additional truthful observations/audits. It does not certify a globally optimal route. A negative terminal certificate requires every route to have an observed failing compatible world AND no permitted unanswered observation can split the compatibility class. An unavailable observation remains unanswered for this test, even after its one acquisition opportunity has been consumed. Otherwise status is unknown. A fully observed class lacking a common route is observationally irreducible for this robust fixed-route contract, even if each member has some different feasible route. Query/certificate checking reads trusted cache only; model text never creates facts.

Certificate binding includes public input, VM, quota and paid observation references. Runtime chooses only a verified route; the gateway still enforces grants, quotas and receipt signatures. The theorem excludes external state drift and arbitrary natural-language program semantics. Omitted worlds, tampered records, stale status and missing observations are tested as assumption failures, not silently fixed.

## Acquisition and comparisons

Deterministic controls: original-first audit, adaptive route cover, observation-and-route cover, seeded random, and exhaustive audit. All receive the same public input, candidate capacity and trusted query capability. An omniscient reference lower bound is labelled as such and never exposed to selectors. Query budgets 2,4,8,12 and full are reported; no silent fallback from invalid model responses.

Prospective API study uses variant 0 from each of 36 families across the two cohorts, one actual world selected deterministically from case ID before outcomes, and two approved models. Four cells per model/case: source online, graph online, padding online, source fixed; 288 streams total, each at most 12 queries. Graphs are deterministic static edges of all public routes, never extra truth. Graph/padding are exactly matched with the installed o200k_base tokenizer; this is a surrogate control, because the installed tokenizer cannot map GPT-6 Luna automatically. Actual API input tokens are reported separately. The next-query schema is identical across views, max output 1024 for both models, no retries. Models receive public input and paid facts. Every stream has a disjoint deterministic replicate ID: no cross-stream raw-response reuse. Fresh online/fixed streams may diverge because model selection is stochastic, so empirical completion equality is not assumed. Matched-prefix replay provides a separate same-decisions analysis. Submission order is fixed by hash; four workers dispatch subsequent requests in completion-dependent order through one locked inherited budget ledger. If the cap censors requests, this scheduling dependence is reported and censored cells remain in unconditional results; no deterministic dispatch-order claim is made. Decision attempts, confirmed provider responses, uncertain sends and pre-I/O budget rejection are counted separately.

True online stopping checks the certificate before creating/dispatching another request. Fixed acquisition continues to its declared budget and separately records the earliest certificate. Report actual API calls, tokens, conservative upper-dollar estimates and wall latency; parallel wall latency is descriptive. An offline matched-prefix replay is secondary and never called invoice savings. Models are selectors only; they cannot self-certify success.

## Commit status

A trusted status service binds operation ID, exact signature, execution epoch and terminal outcome. Outcomes: committed with authentic receipt, fenced terminal noncommit, pending, unavailable, stale/mismatched. Only the first two can license continuation; absence alone cannot. Effects and terminal status must be atomic/durable in the abstract service. Query costs consume a separate bounded status budget, are logged, and cannot exceed the shared call quota. No unlimited polls. Unsafe blind retry and retry-on-absence appear only as synthetic negative controls. The production controller retains fail-closed behavior when evidence is missing or invalid. Cross-route repair is outside the first theorem; continuation retries the certified route with preserved receipts.
