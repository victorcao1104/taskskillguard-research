# Prospective Phase 8 analysis details

Primary population: all 432 replicate-zero requests, each candidate retained in all three axes. Invalid responses predict the separate invalid category and stay in denominators. Repeats are reported separately. New heldout and prior regression populations never pooled for a claimed generalization gain.

For each model/view/split/axis: typed correct/total, complete confusion matrix, unknown true count/recall, false unknown, true NA and false NA, exact-case success, valid response count, mean input/output tokens and total conservative usage cost. F: global and candidate fact errors, full-fact acceptance, label accuracy conditional on correct facts (undefined if zero). T: residual label errors with exact facts. Deterministic solver is the computational ceiling within this DSL and receives credit for all execution work, never an LLM speedup.

Fresh matched comparisons F-D and T-D: average each axis accuracy within each authored family, then average across families; 10,000 paired bootstrap family draws, seed8008. Cases and candidates within a family are dependent. Repeat stability: three runs per selected case/model/view, exact three-axis labels and (for F) exact facts separately. Invalid outputs do not count as stable semantic correctness. Historical Phase7 B1 versus new D on the SAME 24 cases is a longitudinal rerun, not paired simultaneous treatment; F versus old B2 has protocol and acquisition-time differences.

Recovery summary groups by split/quota/fault/policy: successes/conditions, charged calls, planning steps, unauthorized/duplicates/overquota, failure causes. Pair cost_equal vs priority_equal and each vs v7_safe using exact case/world/quota/fault. Report success wins/losses, call delta over all and both-success pairs, planning deltas, and positive/negative per-family mean success differences with exploratory CIs. Policy paths may diverge and later encounter different faults; identical candidate simulation is required only for shared observations, not falsely asserted for all later paths.

Integration groups by split/pipeline/policy/fault and by alternative count zero/nonzero plus initially feasible alternative zero/nonzero. Initial feasibility is computed using the enforcing receipt-aware runtime from the INITIAL world, not unguarded reference semantics. Use all_allow vs all_block paired success to define observed gate-sensitive conditions. Compare model/solver success on those same conditions and model false allow with trusted gateway rejections. Aggregate solver gates use allworld typed authorization; they are conservative across supplied worlds and are not a per-world execution-success ceiling.

Failure rows retain case, family, world, fault, policy, pipeline, reason, raw evidence reference. No response exclusion, post-outcome prompt changes, cherry-picked case reporting, or claimed universal dominance. All CIs exploratory, no multiplicity correction, no statement of population prevalence beyond authored synthetic families. Graph benefits are not tested anew in this round.
