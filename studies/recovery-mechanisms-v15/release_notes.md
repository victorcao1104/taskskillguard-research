# v15: Skill 被阻断后的恢复机制与适用边界

本版本保留 v14 论文和全部旧实验，按用户要求继续纯合成，并加入服务故障模拟。完整中文分析位于 `studies/recovery-mechanisms-v15/reports/REPORT_ZH.md`。

主要新增证据：

- 七个旧失败全部复现。仅移除任务未要求的依赖与冲突约束后，7/7 通过复查；单纯增加执行预算仍为 0/7。旧得分不改写。
- 16 个模板、四种计算结构、五种源码完整度。完整计算保留时，Full 16/16 且无需模型请求；损坏后没有普遍优势。专用确定性求解器保留，并通过全部模板及规模测试。
- A 原始状态、B 可信状态、C 剩余操作、D 自动执行的严格对照。Luna 可行完成为 41/48、33/48、45/48、48/48；Mini 为 16/48、17/48、17/48、48/48。结果支持区分信息支持与执行保障，不支持“状态信息越多越好”。
- 分离缓存检查、回执处理、重复尝试与真正重复操作；加入成对停止边界、部分执行和有限服务故障。
- 公平数量/逻辑成本下的验证对照保留负面结果。探索性语义边界测试明确披露作者构造和部分输入重合，不宣称对未知缺陷普遍占优。

复现与保留：

- 主实验 864 组回放 24,042 个执行世界，严格状态对照 512 组回放 20,512 个执行世界，结果与保存记录一致；回放不调用 API。
- 55 项测试、1,072 个子检查通过。原始请求、回答、失败、冻结定义、协议变更和预算账本均保留。
- 首次状态对照的控制不足、Windows 路径/DNS 故障、环境补跑规则和一处验证器类型错误处理修补均单独披露。通信失败不被当成模型能力失败，也没有从账本中抹去。
- 新增保守费用上界 $6.3376851，其中有 token 用量的上界 $1.483756725，未决预留 $4.853928375；继承额度尚余 $9.430934925。它不是服务商账单。

本版本支持的是有条件的机制结论；没有证明 Full 普遍优于修复或重新规划，也没有证明真实 Skill 上的安全性或首创性。旧版本存档：`archive-before-mechanisms-v15-20261018`；原主结果存档：`archive-v15-primary-before-strict-state`。
