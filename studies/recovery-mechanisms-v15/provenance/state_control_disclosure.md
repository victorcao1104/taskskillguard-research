# Post-formal review finding and correction

The original 512 state episodes supplied the same fixed compute() function but did not forbid direct input reads inside model effects. Eight selected state programs used direct current-input reads, and 35 saved attempts contained such reads. The original state control therefore fixed tool availability, not all executed computation. Original requests, responses, outcomes, code and statistics remain unchanged.

The independent reviewer identified this after the 864-episode original campaign. A separate 512-episode enforced-computation supplement was authorized within the same synthetic scope and remaining budget. It uses a new frozen protocol and request namespace; no original outcome is replaced. All support groups share the same restriction on effects reading current input, while the fixed compute component retains its existing read authorization. Valid-cache reuse remains permitted. Results across the two interfaces are descriptive, not paired draws from identical prompts.

Two pilot templates occur in the original formal template set. The primary 16-template result follows the prospective design; a separately marked exploratory 14-template sensitivity excludes them. Main attack source uses one removable private-read gate. These qualifications must accompany paper claims.
